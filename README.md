# Freelancer Calculator

> **在线网站：** <https://uu9988.github.io/freelancer-calculator/><br>
> **当前状态：** 已上线；本地审计通过，39 个可索引 URL<br>
> **开发文档：** [开发者指南](docs/DEVELOPER_GUIDE.md) · [AI 协作规则](AGENTS.md)

Freelancer Calculator 是一组面向自由职业者的免费计算与实用指南，涵盖小时费率、收入、项目报价、税务估算、费用与盈利能力等主题。

## 主要功能

- 首页交互式小时费率计算器与结果图表
- 自由职业收入、报价、成本、税务等专题工具页面
- 面向自由职业者的操作指南与博客文章
- 适配 GitHub Pages 项目子路径的静态部署
- 技术 SEO、结构化数据、站点地图与内部链接审计

## 技术栈

- HTML5、CSS3、原生 JavaScript
- Chart.js（CDN）
- Python 维护与审计脚本
- GitHub Pages

项目没有构建步骤、后端服务或数据库。

## 快速本地运行

从项目的父目录启动 HTTP 服务器，以复现 GitHub Pages 的子路径：

```powershell
cd E:\codex\AI-Projects
python -m http.server 8000
```

打开：<http://localhost:8000/freelancer-calculator/>
